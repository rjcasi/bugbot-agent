# Lab 09 — File Monitor (Defense Script)

## Goal
Watch a directory and log when files are created, modified, or deleted.

## Skills
- file I/O
- polling or watchdog-like patterns
- basic alert logic

## Tasks
1. Monitor a folder path for changes.
2. Print events when files change.
3. Log events to a file.

## Stretch
- Add basic rules (e.g., unexpected extensions, large size changes).

## Integration
Connect this to a future "Defense" panel in the cockpit with live events.
