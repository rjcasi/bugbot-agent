# Lab 10 — Cybernaut Agent Lab (Unified Capstone)

## Goal
Build a Python Cybernaut Agent that uses skills from previous labs:
- logging
- recon
- fuzzing
- monitoring
- crypto checks

## Skills
- classes and state
- composing utilities from prior labs
- clean CLI or API entrypoint

## Tasks
1. Define an `Agent` class with state (goals, logs, tools).
2. Give it actions that reuse code from earlier labs (e.g., recon, scan, analyze logs).
3. Build a `main.py` that lets the user choose actions.

## Stretch
- Connect it to the BugBot / Cybernaut cockpit via an API.
- Track agent runs and show them in your Evolution Organ.

## Integration
This is the bridge between your Python Course and the living CyberArena organism.
