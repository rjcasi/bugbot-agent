# Lab 02 — Port Scanner (Defensive Awareness)

## Goal
Build a simple TCP port scanner to understand how services expose ports and how defenders see their surface.

## Skills
- Python `socket`
- iterating over port ranges
- timeouts and error handling

## Tasks
1. Ask the user for a host (IP or domain).
2. Scan a small set of common ports (e.g., 20–1024).
3. Print which ports are open.

## Stretch
- Add colored output (open/closed).
- Add a simple timing summary.

## Integration
This lab can later feed into a "Network Surface" section of your Cybernaut cockpit to visualize exposure.
