# Lab 10 — Password Auditor (Safe Strength Checker)

## Goal
Build a Python script that evaluates password strength using safe, defensive rules and entropy estimation.

## Skills
- regex pattern checks
- entropy calculation
- scoring systems
- defensive automation

## Tasks
1. Ask the user for a password.
2. Score it based on length, character variety, and patterns.
3. Estimate entropy.
4. Provide a strength rating.

## Stretch
- Add a JSON output mode.
- Add a CLI for batch auditing.
- Add a "suggest improvements" feature.

## Integration
This lab can later power:
- a "Password Strength" tile in the Cybernaut cockpit
- defensive education modules
- Evolution Organ learning from password patterns
