# Lab 01 — OSINT Recon Automation

## Goal
Use Python to collect and parse public information (OSINT) from a website in a safe, ethical way.

## Skills
- `requests` for HTTP
- `BeautifulSoup` (or similar) for HTML parsing
- basic data cleaning and printing structured results

## Tasks
1. Fetch a public web page (e.g., a documentation or blog page).
2. Extract all links, titles, and headings.
3. Print a clean summary to the terminal.

## Stretch
- Save results to a JSON or CSV file.
- Add command-line arguments for the target URL.

## Integration
Later, this lab can power a "Recon" tab in the Cybernaut / Python Lab cockpit panel.
