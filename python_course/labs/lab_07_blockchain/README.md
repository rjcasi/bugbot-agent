# Lab 07 — Blockchain Reader (Read-Only Web3)

## Goal
Query public blockchain data safely (read-only) using Python.

## Skills
- web3.py basics (if available)
- connecting to a public RPC
- reading balances or contract state (no txs)

## Tasks
1. Connect to a testnet or mainnet via RPC URL.
2. Read the balance of a given address.
3. Print results in human-friendly form.

## Stretch
- Read public data from a simple contract (e.g., a name or counter).

## Integration
Could power a "Chain Telemetry" tile in an advanced Cybernaut panel.
