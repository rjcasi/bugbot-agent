# Lab 05 — Web Scraper Bot (Automation)

## Goal
Build a Python bot that collects structured data from a paginated website in a safe, ethical way.

## Skills
- HTTP requests
- HTML parsing
- pagination handling
- structured data extraction
- rate limiting

## Tasks
1. Choose a target site (documentation, blog, or any public page).
2. Fetch the first page.
3. Extract titles + links.
4. Detect and follow pagination.
5. Store results in a clean structure.

## Stretch
- Save results to JSON or CSV.
- Add a delay between requests.
- Add a CLI interface for choosing the URL.

## Integration
This lab can later power:
- a "Data Harvester" panel in the Cybernaut cockpit
- OSINT modules for your Cybernaut agent
- RB-App intelligence feeds
