# Lab 05 — Web Scraper Bot (Automation)

## Goal
Automate collection of structured data from a paginated website.

## Skills
- HTTP requests
- parsing pages
- handling pagination safely

## Tasks
1. Choose a paginated site (e.g., docs, blog listings).
2. Fetch multiple pages.
3. Extract and store titles + links.

## Stretch
- Save to CSV or JSON.
- Add a simple delay between requests.

## Integration
Can later be wired as a "Data Harvester" panel feeding into Cybernaut.
